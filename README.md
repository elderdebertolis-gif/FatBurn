# FatBurn

Aplicacao de treino e acompanhamento fisico com:

- `mobile`: app Expo + React Native
- `backend`: API Node.js com PostgreSQL
- `portal`: painel web do instrutor

## Estrutura

```text
FatBurn/
├── backend/
├── mobile/
└── portal/
```
