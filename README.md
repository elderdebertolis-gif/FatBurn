# FatBurn

Aplicacao de treino e acompanhamento fisico com:

- `mobile`: app Expo + React Native
- `backend`: API Node.js com PostgreSQL
- `portal`: HTML, CSS e JavaScript

## Estrutura

```text
FatBurn/
├── backend/
├── mobile/
└── portal/
```

## Objetivos

- Desenvolver um aplicativo de celular que com base nas informações do usuário (peso, altura, idade e objetivo), proponha treinos em casa ou utilizando aparelhos da academia. Também demonstrar como executar cada exercício por meio de um vídeo explicativo;
- Facilitar o acesso dos usuários a essas informações, visando a melhoria da qualidade de vida da população;
- Minimizar a necessidade de um acompanhamento de um personal trainer durante seu treino, visando usuários que não tem condições de pagar por um.
- Promover a saúde e bem estar da população.
- Incluir pessoas de baixa renda, mostrando exercícios que podem ser feitos em casa.
- O projeto foi desenvolvido com Expo e React Native no aplicativo mobile, utilizando TypeScript para a implementação das telas e regras de negócio. O backend foi construído em Node.js, com integração ao banco de dados PostgreSQL. O portal web do instrutor foi desenvolvido com HTML, CSS e JavaScript. Para hospedagem e distribuição, foram utilizados Render, GitHub e EAS Build (Expo).
