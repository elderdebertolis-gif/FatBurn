# Branding Assets

Salve aqui os arquivos finais de logo e icones do FatBurn.

Arquivos usados atualmente pelo app:

- `logo-horizontal-dark.png`
  Usado no cabecalho interno do app.
  Tamanho sugerido: `1600x400`, fundo transparente.

- `logo-stacked-dark.png`
  Usado nas telas de loading/login e no splash.
  Tamanho sugerido: `1200x1200`, fundo transparente.

- `app-icon.png`
  Usado como icone principal do app no Expo.
  Tamanho sugerido: `1024x1024`.

- `adaptive-foreground.png`
  Usado no `adaptive icon` do Android.
  Tamanho sugerido: `1024x1024`, com bastante area transparente ao redor.

- `adaptive-monochrome.png`
  Usado na versao monocromatica do `adaptive icon` do Android.
  Tamanho sugerido: `1024x1024`, fundo transparente.

Observacoes:

- Pode substituir os arquivos mantendo exatamente os mesmos nomes.
- Depois de trocar os assets, rode `npx expo start -c`.
- Para refletir os icones Android no APK final, gere uma nova build do app.
